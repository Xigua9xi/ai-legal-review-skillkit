# Synthetic EPC Contract - Scope Conflict

This is a synthetic fixture for testing. It does not describe a real project.

## Main contract

The contractor is responsible for equipment supply and commissioning.

## Technical agreement

The contractor is responsible for equipment supply, civil works, installation, grid connection testing, and final project acceptance.

## Quotation sheet

The quotation only includes equipment supply and basic commissioning service.

## Risk pattern

The main contract, technical agreement, and quotation sheet define inconsistent scope boundaries.

## Expected review focus

- Scope inconsistency across documents.
- Missing document priority order.
- Need to clarify civil works, grid connection, testing, and final acceptance responsibility.
